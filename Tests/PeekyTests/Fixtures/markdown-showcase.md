# Markdown 阅读体验

清晰的标题、舒适的间距，以及适合长文阅读的原生排版。支持 **重点内容**、*斜体*、~~删除内容~~ 和 `inline code`。

- [ ] 确认最终效果

> 好的阅读体验来自清楚的层级与稳定的排版。
> 引用使用左侧边线，与正文自然区分。

## 代码示例

```swift
struct Preview {
```
